Panduan Mengatasi HDD Tidak Terbaca

Langkah-langkah sistematis untuk memperbaiki masalah HDD di laptop atau komputer.

1. Cek Melalui Disk Management

Seringkali HDD terdeteksi sistem tapi tidak muncul di File Explorer karena belum diberi Drive Letter atau statusnya masih Unallocated.

  • Tekan Windows + X → pilih Disk Management.
  • Cari disk Anda di daftar bawah.
  • Jika Unallocated: klik kanan → New Simple Volume → ikuti wizard.
  • Jika Healthy tapi tidak muncul: klik kanan → Change Drive Letter → pilih huruf baru.

2. Aktifkan Melalui Device Manager

  • Klik kanan Start → pilih Device Manager.
  • Buka Disk drives.
  • Klik kanan HDD bermasalah.
  • Pilih Enable device atau Update driver.
  • Jika perlu, Uninstall device lalu restart.

3. Cek di BIOS / UEFI

  • Restart komputer, tekan F2, Del, atau sesuai merk.
  • Cek menu Storage/Boot apakah HDD terdeteksi.
  • Jika terdeteksi → masalah software. Jika tidak → kemungkinan kabel/fisik HDD rusak.

4. Periksa Fisik dan Kabel

HDD Eksternal: coba port USB lain, ganti kabel, atau tes di komputer lain.

HDD Internal: matikan PC, cek kabel SATA & Power, ganti kabel atau port jika perlu.

5. Gunakan CHKDSK

  • Buka Command Prompt sebagai Administrator.
  • Ketik: chkdsk E: /f /r (ganti E sesuai drive).
  • Tunggu proses selesai.

Catatan: Jika HDD berbunyi klik atau tidak berputar, kemungkinan rusak fisik. Gunakan jasa recovery data profesional bila datanya penting.
