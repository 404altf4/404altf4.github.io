Untuk Mematikan AutoPlay di Windows 11

Langkah-langkah Menonaktifkan AutoPlay

Ikuti panduan berikut untuk mematikan AutoPlay secara manual di Windows 11.

Langkah 1: Buka Settings

Tekan kombinasi Windows + I untuk membuka menu Settings.

Langkah 2: Masuk ke AutoPlay

Pilih menu Bluetooth & devices, lalu klik AutoPlay.

Langkah 3: Matikan AutoPlay

Geser switch Use AutoPlay for all media and devices ke posisi Off.
